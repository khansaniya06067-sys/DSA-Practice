# DSA Practice

This repository contains my solutions to **LeetCode problems** that I solve while preparing for coding interviews and improving my problem-solving skills.

All solutions are implemented in **Java**.

## About

I use this repository to keep track of the problems I have solved and to revise important DSA patterns.

The problems are organized by topic, with each problem stored in a separate directory.
