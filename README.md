# DSA Practice

This repository contains my solutions to **LeetCode problems** that I solve while preparing for coding interviews and improving my problem-solving skills.

All solutions are implemented in **Java**.

## About

I use this repository to keep track of the problems I have solved and to revise important DSA patterns.

The problems are organized by topic, with each problem stored in a separate directory.

## Repository Structure

```text
DSA-Practice/
│
├── 2213-longest-substring-of-one-repeating-character/
├── 2958-length-of-longest-subarray-with-at-most-k-frequency/
├── 3090-maximum-length-substring-with-two-occurrences/
│
├── README.md
└── stats.json
```

Each problem directory contains the solution for that particular LeetCode problem.

## Topics

The repository will cover commonly asked DSA topics, including:

* Arrays
* Strings
* Hashing
* Sliding Window
* Two Pointers
* Binary Search
* Linked Lists
* Stack & Queue
* Trees
* Graphs
* Heap / Priority Queue
* Recursion & Backtracking
* Greedy
* Dynamic Programming

## Solutions

For each problem, I focus on:

* Understanding the problem before coding
* Finding an efficient approach
* Writing a clean Java solution
* Understanding the time and space complexity
* Identifying the DSA pattern used

## Language

**Java**

Solutions are written using Java and follow the standard LeetCode format wherever applicable.
